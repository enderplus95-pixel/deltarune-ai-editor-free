# DELTARUNE AI Editor Free

A lightweight starter workspace for planning and building Deltarune-inspired mods and custom styles with AI assistance.

## Quick start

1. Open `ai-start.bat` on Windows.
2. Read `docs/getting-started.md`.
3. Edit `project/mod.json` to describe your mod.
4. Add content under `assets/` and `src/`.

## Project layout

- `project/mod.json` — mod name, author, version, and metadata
- `assets/` — sprites, sounds, maps, and other media
- `src/` — scripts and source files
- `docs/` — guides and notes
- `templates/` — reusable templates
- `tools/` — utility scripts

## Safety

This repository is a fan-made workflow and does not include or redistribute game files. Only add assets you own or have permission to use.
