# Getting Started

## 1. Describe your idea

Choose a clear goal before generating content. Include:

- The story premise
- Main characters
- Areas and maps
- Art style
- Gameplay mechanics
- Dialog tone

## 2. Configure the project

Edit `project/mod.json` with your mod name, ID, author, description, and version.

## 3. Add content

Place source files in `src/`, images and audio in `assets/`, and documentation in `docs/`.

## 4. Test safely

Back up original files before using them with a modding tool. Test changes in a copy of the project and keep assets organized.
